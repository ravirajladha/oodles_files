# Oodles Files

## Overview
Oodles Files is a web application built using the PHP MVC framework to assist students in preparing for quizzes and exams. It supports a wide range of academic levels, from Class 6 to competitive banking exams, offering tools for quiz creation, practice, and performance tracking.

## Features
- **Quiz Creation**: Generate custom quizzes tailored to different subjects and exam types.
- **Practice Mode**: Interactive sessions for students to test their knowledge.
- **Progress Tracking**: Monitor performance with detailed results and analytics.
- **User-Friendly Interface**: Simple design for easy navigation.

## Tech Stack
- **Backend**: PHP (MVC architecture)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL (configurable)
- **Server**: Apache/Nginx

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ravirajladha/oodles_files.git
   ```
2. Navigate to the project directory:
   ```bash
   cd oodles_files
   ```
3. Copy `.env.example` to `.env` and configure your database settings.

## Usage
- Access the application via `http://localhost:8000` (or your server URL).
- Register as a student or admin to create and take quizzes.
